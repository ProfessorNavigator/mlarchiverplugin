# MLArchiverPlugin

Plugin for [MyLibrary](https://github.com/ProfessorNavigator/mylibrary). Creates and edits archives.

## Description
This plugin is suitable for archives creating and editing. Supported types of archives: zip, 7z, jar, cpio, iso, tar, tar.gz, tar.bz2, tar.xz.

## Installation
`cmake -DCMAKE_BUILD_TYPE=release -S <path_to_sources> -B <path_to_build_dir>` \
`cmake --build <path_to_build_dir>` \
`cmake --install <path_to_build_dir>`

Default installation path is `/usr/local/<libdir>/MLArhciverPlugin`

## Dependencies
You need [MyLibrary](https://github.com/ProfessorNavigator/mylibrary).
