# MLArchiverPlugin

Плагин-архиватор для [MyLibrary](https://github.com/ProfessorNavigator/mylibrary).

## Описание
Данный плагин предназначен для создания и редактирования архивов. Поддерживаемые типы архивов: zip, 7z, jar, cpio, iso, tar, tar.gz, tar.bz2, tar.xz.

## Установка
`cmake -DCMAKE_BUILD_TYPE=release -S <path_to_sources> -B <path_to_build_dir>` \
`cmake --build <path_to_build_dir>` \
`cmake --install <path_to_build_dir>`

По умолчанию плагин будет установлен в `/usr/local/<libdir>/MLArhciverPlugin`

## Зависимости
Для сборки требуется [MyLibrary](https://github.com/ProfessorNavigator/mylibrary).
